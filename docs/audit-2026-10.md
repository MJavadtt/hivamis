## UI-3 — the glass, measured

**The sweep.** `apps/api/scripts/contrast-audit.ts` runs axe-core's `color-contrast` rule in
Chrome against WCAG AA:

- light and dark;
- signed out, and as the administrator and a designer;
- every page, every tab and the first record of each list: 129 screens per theme.

**The first run found 50 distinct failures, 1,825 in all.** Each traced to one of five causes:

| Cause | Where | Fix |
| --- | --- | --- |
| `ink-400` used as text: 2.6:1 in the light, 4.3:1 in the dark | 169 places, among them the sidebar's group headings on every screen | The token itself: 400 and darker are text. Light `#6a6684`, dark `#9490b2`. 500 and 600 move down a step to keep the scale |
| Status text in the fill shade: `text-rose-600`, `-500`, and amber, sky and emerald 600 | 26 places: overdue dates, "not recorded", required-field stars | 700 is the text shade in both themes. Light amber 700 is darkened to `#a34400` |
| A faded card or button (`opacity-70`) | Forms not open to your unit; transition buttons whose guard fails | The fade is gone. A dashed edge, or a rose ring beside the existing red count, says it instead |
| `bg-brand-600 text-white` | Chosen toggles and the selected day: in the dark, brand-600 is the lifted text shade | The accent gradient (`btn-accent`) |
| — (found by measuring, not by axe) | White on the accent gradient: 3.7:1 at its blue end, 3.2:1 hovered | New stops `#6150ea → #4f5fe6 → #336bd0`; the hover stops are lighter but each keeps 4.5:1 |

**After the fixes: no failures.** The same sweep, all 258 screens in both themes, found 0 failures.

axe leaves some text undecided. It cannot compute text over a gradient (478 cases: the accent
buttons, the chosen item), and some text is partly covered by another element (the owl, a sticky
header). The gradients are covered by computation in the token test below. The partly covered
texts use the same tokens as text axe did measure.

**What axe could not see.** The glows are a pseudo-element's gradient behind the glass, so axe
measured the glass over the plain canvas. Over the strongest glow, light glass at 58% is
`#e7e2ff`, and even `ink-500` read 4.4:1 there.

- The light glass is now white at 72%. It is still glass, and its darkest point is `#efebff`.
- `contrast-tokens.test.ts` rebuilds that worst case from the tokens themselves: the canvas, the
  surface's opacity and each glow. It requires 4.5:1 for every text shade and every gradient stop,
  in both themes.

**Blur and slow devices** are described in ADR-081:

- every blur is a token;
- three overlays that ignored `prefers-reduced-transparency` now honour it;
- `data-power="low"` turns the glass solid on a device with four cores or fewer, or one already
  missing frames.

## UI-V — the visual pass

`apps/api/scripts/screen-sweep.ts` signs in as each of the seed's twelve roles and walks every page
the role's navigation offers, plus `/me`, `/delegations` and the phone app. It covers every tab and
the first record of each list, on a desktop (1440×900) and a phone (390×844). It runs against a
frozen copy, a production build and an API on a copy of the database, so nothing it does touches the
data people use. On each screen it records:

- console errors and uncaught exceptions;
- failed requests, and answers of 5xx;
- a page wider than the window;
- a control cut off at the edge;
- a record's code broken across lines;
- a raw API value shown instead of words;
- Latin digits in a Persian sentence;
- in English, Persian left in buttons, headings, labels and tabs.

Screenshots of each page as it opens, for each size, are in `docs/screens/desktop` and
`docs/screens/phone`. The dashboard, My Work and the phone app are shot once per role, since they
differ by role.

**Found and fixed:**

| What | Where | Fix |
| --- | --- | --- |
| Record codes broken at their hyphen (`PRJ-` / `000016`, `F-1404-` / `118`) | Most lists and details: leads, projects, briefs, proposals, forms, invoices, contracts, work orders, revisions; worst on a phone | The `Code` component and 22 code and number cells never wrap |
| A raw value: payment method `TRANSFER` | Finance › payments | Shown in words (`PAYMENT_METHODS`) |
| A raw value: audit action `REFRESH_TOKEN_REUSE` | Admin › audit trail | All 46 actions the API writes are named. `audit-labels.test.ts` reads the API's source, so a new action cannot arrive without a name |
| Latin digits in Persian sentences from the server: «دست‌کم 12 واژه»، «بر پایهٔ 5 بریف»، «خطای 404» | Brief quality, rules, errors, notes | `trx` and `loc` write Persian digits in Persian text, leaving codes, model names and addresses as they are (`faDigits`); the rule builder's read-back goes through `trx` too |
| A badge wrapped inside its pill («ضعیف — ۳۷ از ۱۰۰» on three lines) | Brief quality on a phone; any long badge | Badges never wrap |
| The profile card squeezed to one word a line | `/me` on a phone | The name's column has a minimum width; the link wraps below it |
| Session renewal limited per address | Found when the sweep lost its session | UIV-1, its own commit |

**Not changed, on purpose:**

- **The owl's greeting.** On a phone it covers a third of the screen until dismissed. It is a
  first-visit greeting with a dismiss button, and the sweep dismisses it as a person does once.
- **The floating owl.** It sits over the bottom corner of content, as a floating button does. The
  content scrolls out from under it, and the footer keeps its corner clear.
- **Acronyms and names inside sentences.** CSAT, HMAC, WOFF and `ANTHROPIC_API_KEY` in a setup note
  are terms, not raw values. The detector flags a value only when it stands alone.

**Clean throughout:** no console error, no failed request, and no page wider than the window, for any
role at either size.

**The figures:**

- **The first full run:** 608 findings, 88 of them distinct.
  - 416 were wrapped codes.
  - 192 were all-caps words. Two were raw values; the rest were terms inside sentences, which the
    detector now leaves alone.
- **The run after the fixes** (the screenshots are from it): 69 distinct.
  - **Three wrapped codes remained.** The contract numbers in the contracts list are fixed since;
    an invoice code inside a sentence of the accounting export is left as it is.
  - **66 from the digits detector, new in that run:**
    - the related-forms count, fixed since (Persian digits);
    - IP addresses and a Latin citation («Doc_H slide 34»), now left as written by `faDigits` and by
      the detector alike;
    - the demo leads' names («سرنخ 1») and an SMS code in the sandbox's message, which are data, as
      typed.
