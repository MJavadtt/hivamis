### تصمیم:

**الف) مشتری تأیید کرد:**
→ ورود به فرآیند قرارداد

**ب) مشتری اصلاح خواست:**
→ فروش درخواست اصلاح دقیق را به اکانت منتقل می‌کند
→ اکانت Scope اصلاح را مشخص می‌کند
→ در صورت نیاز، درخواست اصلاح به واحد مربوطه ارسال می‌شود
→ واحد اجرایی اصلاح می‌کند
→ اکانت QC می‌کند
→ Proposal اصلاح‌شده به فروش برمی‌گردد
→ فروش مجدداً با مشتری مذاکره می‌کند.

**ج) مشتری Proposal را رد کرد و Proposal جدید خواست:**
→ فرآیند از مرحله تحلیل بریف / Kick-off مجدداً آغاز می‌شود.

هر درخواست جدید مشتری ابتدا توسط اکانت دریافت و بررسی می‌شود.

### تصمیم:

→ اجرا طبق فرآیند عادی

→ بررسی Commercial Impact
→ برآورد زمان و هزینه

# چرخه‌های تکرارشونده اصلی

### چرخه ۱ — نقص اطلاعات
بریف ناقص → بازگشت → تکمیل → ارسال مجدد

### چرخه ۲ — اصلاح خروجی
خروجی واحد → QC اکانت → عدم تأیید → اصلاحیه → واحد اجرایی → خروجی جدید → QC مجدد

### چرخه ۳ — اصلاح Proposal
بازخورد مشتری → اکانت → واحد اجرایی → اصلاح → QC → فروش → مشتری

### چرخه ۴ — Proposal جدید
رد Proposal → تحلیل مجدد نیاز → Kick-off → تولید Proposal جدید

### چرخه ۵ — تغییر Scope
درخواست جدید → بررسی اکانت → بررسی Scope → قیمت/زمان → تأیید مشتری → اجرای تغییر

### چرخه ۶ — فروش مجدد
پایان/حین پروژه → شناسایی نیاز جدید → Opportunity → فرآیند فروش/پروپوزال جدید
